# LAYL — Garden Lobby v1.5

## Run
- Open `index.html` in Chrome, or from this folder run `npm run dev` and visit `http://127.0.0.1:5173`.
- Start opens the garden lobby and Mission 01.
- Guide, Characters, Achievements, Settings, and Credits are interactive from the main menu.
- Mission Control provides a confirmation before returning to the main menu.
- Full screen can be toggled from Settings.
- Owner reset code: `LAYL2026` (demo-only, stored in the browser code; not a secure secret).
